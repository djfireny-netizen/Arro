# ARRO brand assets

Approved initial identity: the complete uppercase ARRO wordmark, with a continuous blue-to-green gradient (#5B7CFF to #34D6A6). The app icon places the same four letters on deep navy (#030716). All letters are vector outlines and require no fonts. The former abstract symbol and orange treatment are not part of this identity.

- `arro-wordmark-v4.svg`: transparent wordmark.
- `arro-icon-v4.svg`: scalable app icon.
- `arro-icon-v4-32.png`: browser fallback icon.
- `arro-icon-v4-180.png`: Apple touch icon.

The landing page serves this folder statically. The application server exposes only the four named image assets before invitation login. SVG sources are authoritative; PNGs are browser-rendered exports of the icon.
